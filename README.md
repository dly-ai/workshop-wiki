# Workshop Wiki

Static site for internal workshops: Ansible Automation Platform, OpenShift Virtualization, and OpenShift App Platform (Security).

No build step. Open `index.html` or `calendar.html` in a browser (double-click is fine).

Buttons use [PatternFly 6](https://www.patternfly.org/) from the jsDelivr CDN (`patternfly-base.css` + the Button component).

## Fill in details later

- Session dates, times, and registration links: `js/site-data.js` (`WIKI_EVENTS`)
- Track name, tagline, overview, agenda, and resource URLs: `js/site-data.js` (`WIKI_WORKSHOPS`)

Tracks: `aap`, `virt`, `security`.

The home page embeds the Arcade registration walkthrough. Written registration steps live in the Registration process section on `index.html`.
